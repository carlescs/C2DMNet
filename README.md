C2DMNet
=======

![Archived](https://img.shields.io/badge/status-archived-red.svg)

> **⚠️ This project is obsolete.**
> [Google's Cloud to Device Messaging (C2DM)](https://developers.google.com/android/c2dm/) service was deprecated on June 26, 2012 and shut down on July 30, 2015. It was replaced first by Google Cloud Messaging (GCM) and later by Firebase Cloud Messaging (FCM). This library no longer works and should not be used in new projects.

C2DM messaging framework for .NET.
